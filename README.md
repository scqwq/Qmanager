# Qman

Windows 上的 QQ 本地媒体管理工具，用于浏览、筛选、导出、备份和恢复已保存的图片、视频、收到的表情及语音文件。

## 快速开始

运行环境：Windows x64，需安装 Microsoft Edge WebView2 Runtime。

### 1.下载使用

下载使用：在 [Releases](https://github.com/scqwq/Qmanager/releases) 选择对应 tag，下载 Windows x64 ZIP 附件，解压后运行 `Qman.exe`。未提供成品的版本可从源码构建。

### 2.源码构建

源码构建：安装 Go 1.25+、Node.js 22.12+（含 npm），在项目根目录执行：

```powershell
.\tools\Build-Qman.ps1
.\build\bin\Qman.exe
```

## 使用

- 导入目录：在设置中搜索或选择 QQ 数据文件夹，保存后导入，切换账号并点击“快速更新”。
- 按年月查找：在“来源月份”中选择年份或月份，月份来自 QQ 文件夹名称。
- 按发现日期查找：切换“新增发现日期”并填写日期区间；查首次导入的旧文件时，勾选“包含首次导入记录”。
- 备份与恢复：点“备份当前筛选”，或在媒体页点“管理”勾选文件，再点新增栏里的“备份”。通过“加载备份”补回源目录或独立查看。
- 导出媒体：点“管理”勾选文件，再点“导出”。可在设置中保存默认导出父目录，留空时每次选择，临时选择只用于本次。
- 删除媒体：点“管理”勾选文件，核对清单、退出 QQ 后确认移至回收站。
- 备份历史：查看状态、重新定位，或展开“保存位置”点击路径打开文件夹。

发现日期是 Qman 首次观察到文件的时间，不代表 QQ 下载时间；核对旧文件的替换或缺失时使用“全盘更新”。

## 功能

- 媒体浏览：按类型、角色、年月、发现日期和大小筛选，支持图片、GIF 和视频预览。
- 索引更新：保存本地清单，支持快速补新、后台监控和手动全盘核对。
- 媒体备份：支持当前筛选、月份范围、整年或跨页勾选，保存为目录包或 ZIP，保留原目录树并校验 SHA-256。
- 媒体导出：将所选文件平铺到新的 `Export-YYYYMMDD-HHMMSS-001` 文件夹，同名文件加编号，结果可直接查看，无法通过“加载备份”导入。
- 加载恢复：从备份补回源目录，已有同内容文件跳过、冲突另存，也可仅保存到 Qman 独立查看。
- 媒体清理：选中文件后核对并确认，移至 Windows 回收站。
- 备份历史：核对备份包、原文件和云盘状态，查看每份备份的操作记录，重新定位或管理本地文件。
- 设置与记录：查找 QQ 目录、保存默认目录、调整主题和背景、导出应用记录并查看运行日志。
- 123云盘：扫码或账号密码登录，可手选文件上传，也可从备份历史上传指定备份。

## 补充

- 索引、设置和运行数据默认保存在 `%LOCALAPPDATA%\Qman\`，不在 EXE 所在目录。
- 扫描、监控、备份和导出只读访问 QQ 源文件。恢复到 QQ 目录或回收源媒体前需退出 QQ 并确认操作。
- 备份包含明文媒体；源文件回收与本地备份包永久删除是两项独立操作。
- 当前为试用版，预览受格式与编码限制；语音暂不播放，尚不支持聊天正文解析。云盘上传须由用户确认发起。

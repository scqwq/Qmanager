# Qman Media Directory 1

## 0.3.0 扩展：范围、ZIP、路径加载与历史删除

目录载荷仍为 qman-media-directory/version=1，新增可选 restore_prefix（账号/nt_qq/nt_data，可附 Pic/Video/Ptt/Emoji/emoji-recv 子根）。它只包含相对路径，不包含原盘符或绝对路径，但包含账号目录标识，属于隐私元数据。旧包缺少此字段时仅独立加载，不猜测目标账号；旧只读查看器可忽略新字段。选择条件新增可选 month_from/month_to（含结束月份），按视图分别解释来源月/发现月，不将年份映射成首次发现日期。

ZIP 是同一目录包的容器，条目只有 manifest.json 与 objects/<SHA-256>；默认 STORE。导出先完成目录载荷，再流式打包、重新有界解包并校验 SHA-256，发布不覆盖；正常清理本次目录中间副本。目录阶段成功后 ZIP 阶段失败可保留完整目录，清理残留不宣称完整。创建按约三倍目标空间预算预检；ZIP 读取还需校验暂存容量，不保证压缩收益。

ZIP 在构造 archive/zip 条目列表前核对中央目录：最多 200001 条、中央目录 64 MiB，支持标准 ZIP64 描述，拒绝分卷。逐项限制 STORE/DEFLATE、重复名称、链接、加密标记、危险路径、长度、CRC、压缩比；清单 32 MiB、有效引用/对象各 200000、唯一载荷总量 2 TiB。解包使用应用创建的唯一私有暂存，绝不按包内任意路径展开到 QQ 目录；上限是资源保护，不是容量实测承诺。

加载由用户选包并完整校验，再明确目标 Tencent Files、映射账号和已退出 QQ。仅媒体白名单映射允许新增；os.Root 限定边界，既有目录合并，同路径同内容跳过，不同内容使用“_备份_<完整SHA-256>”后缀另存，不能安全写入则复制到私有 library/<备份ID>/objects/。以校验后的暂存新文件硬链接原子发布，不覆盖目标；不支持硬链接的目标文件系统回退到独立媒体库。清单/索引不复制进 QQ；不执行取钥/QQ 进程操作，不恢复消息库，不判断 QQ 是否识别。运行中 QQ 或进程状态无法核实则只保存到 Qman。

私有 SQLite 的 backup_records 保存备份编号、原始清单摘要、当前登记位置、选择条件、结果及删除日志；backup_imports 保存原清单与逐项实际保存位置。相同编号/摘要重新加载或重新定位只更新一条记录，同编号不同清单拒绝。不同备份保持独立，不做跨包对象共享；历史仅追踪每份备份最近登记的位置，不自动寻找其他副本。已加载媒体视图保留原时间证据，重开时重新核对实际内容；不强行覆盖账号现有观察账本。已有单包 restored_backups 证据表继续保留。

历史删除仅针对明确选定、已登记、与源和应用数据隔离的备份包，最多 100 份。先校验身份/集合，再持久记录同目录唯一 .qman-delete-* 路径、隔离包并按清单删除成员，不递归删除任意目录；拒绝未知新增文件、变化对象和链接。中断保留删除日志，可重新尝试，已删除记录保留。永久删除不经过回收站，不删除 QQ 源/已补回媒体/独立副本或网盘内容；本版不做源清理。恢复与删除均按项报告，取消不自动删除已成功补回的文件，异常退出暂存残留不自动无界清理。

第一版媒体备份采用自描述目录包，不沿用 `.qqarc`，不生成聊天消息或 SQL。

0.2.2 的选择条件可含可选 include_baseline（省略为 false），仅影响按发现日期是否明确纳入初次基线；包内原 baseline、首次发现和来源月份仍保留，不改成下载证明。格式版本不变。

结构：`manifest.json` 和 `objects/<SHA-256>`。manifest 的 `format=qman-media-directory`、`version=1`；含备份 UUID、UTC 创建时间、来源 UUID/自定义名称（不存绝对源路径）、选择条件、逐文件来源相对路径/类型/月/角色/检测格式/逻辑长度/文件系统时间、首次发现/稳定观察/证据来源/覆盖信息、实例 ID、SHA-256、所选实例的必要事件、未纳入对象及原因。

已识别、非零、非临时、三次间隔至少一秒不变的文件可备份；这只是稳定启发式。复制期间核对身份/大小/修改时间，按实际复制字节哈希，再独立枚举验证整个目录对象集合、长度、SHA-256 和引用。任何复制变化/取消/校验失败均不发布。未知、损坏、临时、零字节、不稳定对象保留清单及原因；可用对象部分备份明确显示警告，不宣称完整。

目标由用户手动选择；源、应用索引及目标相互隔离，拒绝链接。唯一同卷暂存，校验后不覆盖式发布，目录名随机且不覆盖已有备份。选择单月或观察日期；估计所选字节和附加清单空间，检查目标可用空间。目录包不压缩、不加密，不减少源占用。

读取不可信目录时不展开任何内容：清单最多 32 MiB、200000 引用、200000 对象、总载荷最多 2 TiB；对象只允许 64 位小写十六进制 SHA-256 文件名。拒绝额外条目、链接、大小/哈希不符、重复实例、路径穿越、绝对/UNC/盘符路径、ADS、Windows 设备名及未知格式版本。原相对路径只作显示元数据，不用于写盘。预览只打开经过验证的对象 ID，检查对象未被替换，禁执行/远程资源。

打开备份不依赖源目录或原索引，保存的观察证据可在独立备份视图中显示；未保存的观察历史保持未知。恢复观察证据写入应用私有索引副本，不覆盖已有来源历史。索引也应可单独导出为自描述备份。

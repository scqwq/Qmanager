# Qman Media Tree 2

产品0.4.0-preview使用qman-media-tree/version=2。本轮用户明确无需处理已生成备份，不迁移、不读取旧qman-media-directory v1包，也不改动旧包本身。聊天.qqarc格式与本格式无关。

## 目录结构

```text
Qman-日期-编号/
  backup.json
  .qman/files.jsonl
  Tencent Files/账号/nt_qq/nt_data/Pic/2024-08/Ori/原文件名.png
```

backup.json只保存格式/版本、备份编号与时间、来源编号/名称、账号相对映射、载荷根、筛选、条目/文件/字节总数和逐文件索引SHA-256；最多64KiB，不包含逐文件数组或绝对源路径。能验证账号结构时载荷根为Tencent Files；单独媒体目录缺账号映射时使用Media或Media/Pic、Media/Video、Media/Ptt、Media/Emoji/emoji-recv，只能独立加载，不猜账号。

每个原路径各复制一份普通文件，不跨路径或跨月份按内容去重，不用硬链接/符号链接共用载荷。同内容可以有相同SHA-256，但各自的路径、实例、时间证据和观察记录独立保留；统计媒体长度按副本累加。

## 精简逐文件索引

files.jsonl为UTF-8逐行JSON。目录定义形如`{"d":0,"directory":"Pic/2024-08/Ori"}`，路径只写一次；文件形如`{"d":0,"file":{...}}`引用前面已定义的目录。目录编号连续，目录与文件路径按Windows大小写不敏感规则拒绝重复；拒绝未使用目录定义。

文件字段：n文件名、i原实例、v原文件系统身份、z逻辑长度、h实际复制SHA-256、k类型、m来源月、r角色、f格式、s状态、o首次发现方法、c置信、g覆盖证据、b稳定性、t时间、e观察历史、x排除原因。t按修改/创建/首次发现/最近发现/最近变化/稳定观察六项保存UTC RFC3339Nano，空字符串表示未知，不补造下载时间；e为[UTC时间,事件类型,说明]数组。实际成功项可省略recognized和stable_heuristic默认值；所有排除项没有h且不引用载荷。

按行写入/读取、计算索引SHA-256，不把整个外部索引作为一个JSON大对象解析。单行最多1MiB、总索引128MiB、文件记录200000、目录定义50000、单项历史1000、载荷逻辑总量2TiB；这些是保护上限，不是容量实测承诺。现有界面仍会保留有界解析后的条目集合用于独立分页和恢复，并非恒定内存或零成本。

私有SQLite保存相同精简记录的JSON快照（header+records），以便本地包删除后仍能按原实例/SHA预检源清理。快照摘要绑定索引摘要和公共信息。单份登记/观察证据128MiB，加载结果192MiB，私有索引沿用512MiB容量保护；不导入外部SQL、不执行包内脚本。精简不改写首次发现、原实例、baseline或来源月份证据。

## 复制、校验与ZIP

来源始终只读，输出与全部已登记来源/应用数据/恢复根隔离。备份按所选范围冻结实例、真实多次观察后才复制；前后核对身份/大小/mtime，流式SHA-256，唯一同卷暂存。逐路径载荷、说明和索引均完成独立验证后不覆盖发布。未知/未稳定/不可读项保留清单原因，没有可用项不发布，取消清理本次暂存，不删源。

目录包不压缩、不加密。空间按每路径媒体副本及条目元数据估算（64KiB+每条约2KiB，索引预留最多128MiB），不等于实际分配空间或最终成品大小；实际较长历史可能超过预估，I/O失败不发布。ZIP默认STORE，保持原目录树及元数据；当前创建/独立校验同时有目录载荷、ZIP和解包暂存，按约三倍估计预算预检，不承诺压缩收益。

ZIP解析中央目录前限制条目250034、目录字节128MiB，支持标准ZIP64、不支持分卷；拒绝重复/危险路径、ADS/设备名、链接、加密、非STORE/DEFLATE、异常展开量/压缩比。先只提取两份元数据到唯一私有暂存，校验索引后按声明的确切文件/目录集合提取媒体；所有路径使用os.Root限制，拒绝未知新增对象。说明、索引和逐文件SHA-256/长度/引用关系校验通过才返回可用媒体。

## 加载、查看与删除

独立查看按每个原实例保留多路径副本。加载由用户确认目标Tencent Files并手动退出QQ；元数据不复制进QQ，仅按已校验的账号媒体白名单路径新增。相同目标路径同内容跳过；不同内容带完整哈希后缀另存，不覆盖已有数据。无法安全写回或缺账号映射时按原目录树保存到私有library/备份编号，不按内容折叠多个位置。不判断QQ是否识别，不补造聊天对应关系；加载/取消的逐项位置及时间证据保留。

历史登记按每个载荷副本累加大小，重复加载同编号同清单不增历史，同编号不同清单拒绝。重新定位、独立查看、历史批量删包和源清理均使用新格式证据。删除本地包先核对登记摘要、隔离到已登记暂存路径，再验证确切集合/所有剩余摘要，逐个文件和空目录删除；拒绝新增/身份变化/链接，不递归删未知目录。中断允许用户显式继续已登记任务，缺失的已知成员不重新生成，仍保留源媒体和独立副本。

源清理仍独立确认、使用Windows回收站、检查QQ退出及原实例/版本/实际内容哈希；备份成功或包目录存在不自动授权源删除。元数据和明文媒体含隐私，目录树中的账号标识也属于隐私；不上传、不进入Git。

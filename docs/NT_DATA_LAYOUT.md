# nt_data 目录调查

日期：2026-10-30。依据当前机器账号目录实际结构与文件头抽样，不代表所有 QQ 版本。个人路径、文件名、内容和账号不写入本报告。

方法：确认 16 个一级目录；每目录主抽样最多 5 文件，非敏感样本读取前 64 字节；最多向下 4 层、120 目录，每目录最多取 600 项，不跟随链接。补查视频原文件、系统表情、收到的表情和商城表情，最多 80 目录、每处 2 个非空样本。未全盘扫描、未解密或执行文件、未播放或上传媒体、未读日志正文与 msf 内容、未修改源数据。源正由 QQ 使用，不作为一致快照证据。

文件头识别只能证明具有某格式标记，未完整解码，不能独立证明整个文件可用、没有局部加密或整个目录未加密。未知二进制不等于已加密。目录功能没有公开证据的部分明确标为推断。

## 来源与适用边界

- [QQNT_Export 开发分支 README](https://github.com/Tealina28/QQNT_Export/blob/dev/README.md)：说明本地头像资源、系统表情、SILK 解码及 dataline 跨设备会话。仅参考公开说明，未执行或复制代码，不把它的解析能力当作本项目已验证。
- [QFace](https://github.com/koishijs/QFace)：直接从 QQ 的 BaseEmojiSyastems/EmojiSystermResource 同步系统表情，说明该目录并非聊天附件数据库。
- [Tencent/MMKV FAQ](https://github.com/Tencent/MMKV/wiki/FAQ)：说明加密能力、数据和元数据配对；不证明本账号是否采用加密。
- [SILK 解码项目](https://github.com/kn007/silk-v3-decoder)：QQ SILK 需要编解码支持，编码不同于加密。

搜索未找到覆盖本版本全部目录与加密行为的官方说明。网络清理脚本不能作为可删除、内容可重建或未加密的证据；未执行。Mars/xlog 等其他产品日志文档也不能直接证明 QQ qqxlog 的实现。

归档重点仍为媒体资源与数据库中的消息映射；可以独立识别部分媒体，不等于已还原发送者、会话和准确时间。没有得出整个 nt_data 未加密的比例或删除授权。

## 历史聊天归档验证

日期：2026-10-07。环境：Windows amd64，Go 1.25.4。合成与真实数据证据分别记录，不使用真实聊天参与测试。

## 命令与覆盖

```powershell
go test ./...
go vet ./...
go build -o build/bin/qqarchive-cli.exe ./cmd/qqarchive-cli
```

- domain：包含结束日期、跨年、夏令时 23/25 小时整天、反向日期拒绝。
- plain：只读数据库写入失败、源哈希不变、存在 WAL/SHM/journal 时拒绝开发源。
- archive：合成导出、未知类型警告、源路径改名后独立搜索、中文重复文本和大整数 ID 保留、分页、搜索字面量和 SQL 注入输入、取消及源输出隔离。
- 故障包：哈希变化、多余载荷、缺数据库、路径穿越、不支持主版本；另有 Windows 设备名和 ADS 路径拒绝。
- 发布：直接调用发布操作验证已有目标不被覆盖，暂存和原目标内容保持。

受限执行环境下发布操作返回 Access denied；沙箱外合成 archive 测试通过。应区分环境权限失败与普通 Windows 下实际结果，不将受限测试失败隐藏为通过。

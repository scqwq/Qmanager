# Qman 0.2.2 日期与筛选使用说明

这是 Windows 首版试用构建。只管理本机已存在的 QQ 媒体，不登录账号、不解密消息、不注入 QQ，不删除、移动或重命名源媒体。

## 启动与添加来源

关闭旧版窗口，再双击新版 `Qman.exe` 或 `Qman-0.2.2.exe`。需要系统已安装 Microsoft Edge WebView2 Runtime；Go、Node.js、npm 仅开发时需要。重开时会恢复上次选择的账号和本地清单，不自动扫描源媒体；开始监控由用户点击。

点击“选择 QQ 数据文件夹”，可以选择最外层的 `Tencent Files`、迁移后的父文件夹、某个账号文件夹，也可直接选 `nt_data` 或单独的 `Pic`、`Video`、`Emoji/emoji-recv`、`Ptt`。导入的是媒体清单，不复制或移动原文件。程序先发现受支持的媒体根，不逐个打开所有账号的媒体；结果保存在左侧“账号 / 媒体来源”中。核对实际路径后，对当前账号点击“首次建立索引并监控”。

发现限所选范围，最多 6 层、4096 目录、32768 条目、32 个来源，跳过内部链接和非媒体系统目录；达到边界有提示，可以直接选择未被发现账号的目录。不会从整个磁盘自动搜索。账号名称默认是目录标识，可自行改名，不代表已验证昵称或登录身份。

左侧切换账号时，已有索引直接分页显示，不先扫描 QQ；没有索引的账号只在首次点击建立索引时读取媒体。切换来源会停止上一来源的监控。源断开时仍可看已有清单，但缩略图/播放需要原文件可读取；它不是媒体备份。界面显示缓存状态、上次完整核对和整个应用索引的逻辑大小。

已有 0.2.0 索引会从原记录建立查询用的缓存表，首次升级可能有一次本地数据库整理，不重新读取源媒体，不重置首次发现历史。缓存表与观察历史保存在原私有 SQLite 中，不需要安装 Redis，不复制原图片/视频，不使用 Git 仓库保存媒体。

## 查看与筛选

“全部类型”表示当前来源下的图片、视频、表情与语音，不代表文件夹层级。左侧或顶部下拉选择月份，二者同步；顶部排列为“来源月份 / 月份选择 / 新增发现日期”。来源视图的下拉按来源月份，新增发现视图按工具发现月份；不会把来源月当成发现月。另可筛原件/缩略图/封面/临时资源、状态、最小大小。分页每页最多 60 个文件，可切换网格/列表。

“来源月份”仅是文件夹 YYYY-MM 标签；“新增发现日期”按工具首次发现的本地日期筛选，包含结束日。日期更改后自动查询，也可点击“查询”；按日期查询会清除月份限制，选择月份则清除日期区间，以避免两个区间互相排斥。其他类型/角色/状态/大小条件仍生效，可点“清空筛选”。

首次基线中的旧文件标为“扫描前已存在”，默认不列为后续新增。若昨天首次导入，选择昨天仍查不到，可能正是因为全部属于首次基线。新版会显示当前日期下被排除的首次导入数量，并提供“查看首次导入记录”按钮；也可直接勾选“包含首次导入记录”。此时日期表示首次建立索引的时间，原 baseline 标记和 first_seen_at 不变，不代表昨天发送或下载。监听中断或补扫发现的文件也有单独标记。

开始或继续监控时保留现有列表，后台核对源目录；未变化的文件复用之前检测的格式，新增或变化项补充索引。运行中按原生通知更新受影响的文件/子目录，每 2 分钟完整核对补漏，不再每 15 秒重扫整个账号。

扫描/权限/事件丢失/休眠等缺口有状态提示，在线观察不构成一致快照。稳定性仍要求三次间隔至少一秒、非空、已识别且非临时，只是启发式。少量待稳定文件有单独探测；大型首次基线依赖后续核对，备份可用时间不再承诺约 30 秒。停止期间新增只标“中断或核对扫描后发现”。

点击卡片查看图片或尝试播放视频，以及源相对路径、文件时间、首次发现、稳定观察与事件。PNG/JPEG/GIF 有缩略预览（GIF 缩略图为首帧，详情可尝试动图）；缩略解码限 16 MiB/16MP。视频目前只尝试识别到 ISO-BMFF 的本地文件，具体编码依赖 WebView2，失败会提示，不承诺所有 MP4/HEVC 可播。WebP/HEIC 与 SILK 语音播放暂不支持，原件仍可盘点/按条件备份。

## 备份与独立查看

选好类型、月份或观察日期等条件后点击“备份当前筛选”，核对可备份文件、排除项和空间预算，再选择独立目标目录。备份是复制，会增加目标占用，不减少 QQ 源占用。

备份暂停监控，检查容量后在目标同卷唯一暂存目录流式复制，按实际字节计算 SHA-256，独立核对对象集合/大小/哈希，成功后不覆盖发布。未知、临时、零字节和不稳定对象不复制，但保存在清单的排除报告里；部分备份不等于全量备份。取消或失败不发布看似成功的成品。成功后可点击“继续监控 / 补充索引”，中断期间的新文件不会被伪装为连续监控所得。本轮保留备份功能，不增加源删除。

成品为 `Qman-日期-随机标识/manifest.json` 与 `objects/`，请整体保留，不能只保留 manifest 或重命名 objects 下的文件。目录包是明文，不压缩、不加密。

点击“打开并校验备份”，选择成品目录；程序先完整校验再显示，即使原 QQ 目录不可访问或应用索引为空也能查看已备份内容和所保存的时间证据。它只恢复包内已有证据，不补造丢失历史；打开后的观察证据保存到当前私有索引，不覆盖原来源记录。不支持把媒体恢复进 QQ。

## 索引与隐私

应用数据默认在 `%LOCALAPPDATA%/Qman`，索引文件为 `catalog.sqlite`，包含私人路径和观察历史；请勿公开上传。点击“备份观察索引”可导出完整应用索引副本（不含媒体），可用于人工恢复到新的私有副本；首版未提供自动合并导入外部 SQLite 的入口。媒体包保存的所选时间证据则可直接通过“打开并校验备份”恢复。

媒体预览只绑定随机端口的 `127.0.0.1`，使用每次启动随机令牌和当前对象 ID，不开放任意磁盘路径；不上传内容或连接云盘。预览响应禁止缓存，缩略图不落盘。保管好原文件、备份和索引，关闭后不会继续监控。

## 当前验收边界

已通过合成数据测试及本机 WebView2/Vue/Go 启动通信烟雾。尚未完成用户真实 QQ 小样本核验、实际窗口完整点击/视觉验收、真实视频编码播放、大于 4 GiB 文件、断盘/容量不足/休眠故障、干净机器和 WebView profile 生命周期专项测试。它是可试用构建，不是这些能力均已认证的正式发行版。

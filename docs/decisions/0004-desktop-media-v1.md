# 首版桌面、观察索引与媒体目录包

日期：2026-10-30。用户确认 Windows 中文桌面、图片/视频/收到表情月份管理、语音盘点及原文件备份；支持手动添加多个来源、分别查看，源只读。暂停制作后，用户已明确重新授权开始完成首版。

沿用 Go 1.25 工程与 modernc.org/sqlite v1.39.1。Wails v2.17.0（MIT）承接原生窗口与目录对话框；Vue 3.5.44（MIT）、TypeScript 5.6.3（Apache-2.0）、Vite 7.3.7（MIT）、plugin-vue 6.0.0、vue-tsc 2.1.0 构建界面。模板中的 Vue 3.5.0/Vite 7.0.0 经 npm audit 检查发现公开问题，改用修复版本，最终审计零条已知问题，不代表代码安全性证明。依赖固定版本和 lockfile；npm 仅开发构建使用，用户运行 exe 不需要安装 Go/Node。Wails 所需 x/sys 从 0.36.0 调整为 0.46.0，SQLite 主库版本未变，旧核心回归测试通过。Wails CLI 放项目 .local/bin，不改全局 PATH。

使用 Windows ReadDirectoryChangesW 重叠 IO 监听各受支持根的全部月份子树，监听先于基线枚举建立。512 条通知队列、4096 个待关联新增路径、原生事件历史上限 100000；去抖后扫描及约 15 秒周期核对。记录错误/溢出/启动失败/中断/时钟间隔等覆盖证据。首版全量核对而非增量优化，33k 文件性能未重新实测，不承诺实时或秒开。两次扫描间完全出现又消失的内容无法保存，原生路径事件只保存变化证据，不推断消息来源；卷/文件身份无法核实时不强行做身份关联。

来源 ID 使用 UUID；实例和版本单独保存。初次基线的首次发现不是新增下载时间；首次扫描为空也保存已建立基线状态。无新增事件证据的后续新实例标 rescan_after_gap。三次间隔至少一秒的大小/mtime/文件身份观察，且非空、已识别、非临时，才标 stable_heuristic。后续增长建立新版本并重置稳定状态；只表示启发式，不保证下载完整。改名仅由唯一卷/文件身份关联；同内容不同位置不合并记录。事件写私有 SQLite，不写 QQ 侧记号。

预览缩略图通过受控 AssetServer 接口返回重新编码 JPEG，单图 16 MiB/16MP，两个解码任务；PNG/JPEG/GIF 首帧可生成缩略图。完整图片和视频通过随机令牌保护的 127.0.0.1 流式接口提供，支持 Range，最多四个并行读取，不把大视频通过 JS binding 或 Windows AssetServer 整体加载。原件播放器只尝试 ISO-BMFF，编码失败明确提示；WebP/HEIC/SILK 播放后置，无 FFmpeg 依赖，不请求远程资源。

第一版选择目录清单包而非 ZIP64，定义见 MEDIA_FORMAT.md。媒体按 SHA-256 对象实际去重，原路径/时间/观察证据仍逐引用保存。复制/哈希/独立验证流式进行；只在目标同卷暂存，验证后不覆盖发布。备份暂停监控并保留覆盖边界，用户可继续监控；不把间断误报连续覆盖。未知、临时、空、不稳定等不复制但写入排除报告，部分备份不能称全量。打开备份无需原源或索引；保存的观察证据导入私有 evidence 表，旧源记录不覆盖。独立索引备份对应用自身数据库使用 VACUUM INTO 新副本，不对 QQ 数据库执行任何 SQL。

私有数据默认 LOCALAPPDATA/Qman；用户/SYSTEM DACL，受限测试宿主仅额外保留该进程具体 package/capability SID，禁止宽泛组。源和输出路径隔离、拒绝内部链接。预览不落盘图片缓存，WebView profile 在私有目录，媒体响应 no-store；profile 容量和完整生命周期仍待专项验收。

实际 WebView2/Vue/Go 合成烟雾使用显式 QMAN_SMOKE_SOURCE 与隔离 QMAN_DATA_DIR；正常运行不自动读取任何路径、探针不记录内容或路径。窗口控制工具授权超时，未绕过权限，不声称已完成实际点击或视觉验收。

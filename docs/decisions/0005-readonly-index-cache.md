# 外层发现、先显示索引与增量更新

日期：2026-10-30。用户要求优先完善只读读取/缓存，允许选迁移外层文件夹发现账号；定期监控核对可每 1～2 分钟，不要求一次扫描永久免核对。选择默认 2 分钟。备份保留原型，不添加源删除。

discovery 仅在用户选择范围内枚举目录名，最多深度 6、4096 目录、32768 条目、32 个来源，排除 msf/mmkv/log 等非媒体目录，内部 junction/link 不跟随。不读媒体正文、登录或消息数据库，不用数字目录名证明账号昵称；候选路径单独作为来源 UUID，默认显示目录标识，可由用户命名。

沿用已固定 SQLite，不增加依赖/Redis/Git。原 instances/events/coverage 继续保存历史；新增 media_cache 查询投影（仅当前实例，带来源/月/类型索引）、source_reports 与 app_preferences。首次升级从已有实例建立投影，不扫描 QQ，不重置观察证据。UI 按来源在 SQL 中筛选、统计和分页，最多读取当前 60～100 条完整记录；恢复上次来源无需源在线。

开始监控前验证实际根没有跳变，先建立原生监听再后台核对；已有列表保留。每次核对仍检查文件身份/大小/mtime，未变格式结果可复用，原生修改事件强制检测对应文件；目录事件不强制重读全部子文件头。它是元数据复用，不是内容哈希证明；实际预览/复制仍验证当前文件，未知/不稳定不提升为完整下载。

运行期间合并事件，扫描受影响文件或子目录；局部核对只允许对已核实覆盖的路径标缺失，不能删除其他月份索引，不能用局部未见到证明其他路径不存在。唯一文件身份关联改名仍要求旧位置已证明缺失，避免把新硬链接错误当改名。同内容多位置保留多引用。

每 2 分钟完整枚举补漏；停机/溢出/不可读等继续保留覆盖证据。首次扫描旧文件是 baseline，停机期间新增是 rescan_after_gap，只有匹配原生创建事件才是 live_event，均不等于 QQ 下载。少量待稳定文件（最多 128）单独探测，大基线不反复全量扫描。

账本更新只读取当前实例，不再每轮解析全部旧版本；稳定未变项批量更新 seen，不重写完整 JSON/查询投影。查询投影与历史同在私有索引，实际空间显示于界面；不复制媒体、磁盘缩略图缓存暂不新增。观察历史不可当普通缓存清空。

性能证据只使用 5000 条合成元数据：索引 10833920 字节，初始索引约 558ms，一页 60 条查询约 59ms，环境 Windows amd64 / Go 1.25.4。不是 5000 个真实媒体的首次扫描耗时，也不保证真实账号耗时。更大规模、网络盘、长期内存/句柄曲线尚未测。

# 0009 — 备份历史按原实例与内容清理源文件

日期：2026-11-01。用户确认备份只复制、不自动删源；历史须分别提供清理对应原文件和删除本地备份包，并可先手动上传云盘、删本地包，再清理原文件。

沿用私有登记的原清单/摘要，不要求本地包仍存在，不读取云盘或设置云端已验证/可安全删除状态。关联仅使用本机原来源 UUID 和原实例，核对原路径/身份/大小/mtime 及实际存入备份的 SHA-256；不按现有年月筛选扩大。未备份成功项、后新增/替换/重新出现项跳过，不清理恢复副本。若多份记录重叠则去重，证据冲突跳过；一次最多 100 份且必须同原来源，不猜账号。

先显式预检，切换到原来源并展示根/清单，再由用户确认退出 QQ 和保留可用副本。复用 0.3.1 固定清单和 Windows 回收站流程，不永久兜底或自动继续。backup_ids 关联到删除任务，备份行保留最新任务/联合结果；永久删除包与重登记不抹关联。结果查看只读，避免把历史查询变成再次授权。临时/空/未知/不稳定文件沿用现有保护。

外部导入而缺本机原来源关联、迁移或再次出现的新实例不自动清理，可回媒体页手工核对。私有索引历史丢失且本地包已删时无法恢复关联，不宣称可无损重建。

本次仍不实现讨论中的快速/完整索引模式，不改变两分钟核对；不读取 other_project 中参考代码，不新增依赖或做前端简化。真实数据、故障和原生完整交互须另验。

# 0010 — 轻量快速更新与人工全盘核对

日期：2026-11-01。用户接受旧缓存上只补新增及人工全面核对两种入口；快速模式不得每两分钟自动全量。仍仅当前手选账号的受支持媒体子树，不扫描硬盘、全部账号或日志/票据。

快速遍历目录名字，不逐个打开缓存普通文件，实际未知文件才走身份/格式检查；遇具体事件或待稳定路径则有限局部核对，目录提示不触发整棵旧文件重读。不靠目录时间猜测全部变化；停机期间旧路径修改/替换/删除可能保留，界面明确未知，不声称全盘已核对。周期两分钟只补新，溢出/睡眠/读失败记录缺口提示人工全盘，不静默降级全量。

局部 Apply 只读取当前涉及记录，用索引等值/边界前缀查，不每次解析全部旧 JSON；未核对的缓存不 touch seen。KnownPaths 是轻量路径集合，历史稳定队列的最初实现已由 [0011](0011-cache-first-and-on-demand-backup.md) 替代：不再从数据库领取旧pending，备份按固定范围实际核对。source_baseline 单独记首次名字基线（包括空源），不将它写成全盘时间，后续补扫不能错标首次基线。

全盘入口一次完整枚举，核对所有已有实例及缺失，保留历史/首次发现；完成后继续快速监控。源根离线保留缓存，已登记根还在但受支持子目录全空允许核对缺失。起止覆盖证据独立保存，崩溃后的时间仍保守，不伪造下载业务时刻。

预览/复制/删除与备份历史清理继续物理身份/内容验证，缓存未经复核不是授权状态。普通账号投影与 backup_imports/restored_backups 不混淆，加载备份保留原 first_seen_at，不能将加载日改成新增下载；新写回路径需更新来源。

未接入 USN（需另评估权限/覆盖/日志保留），无新依赖或全盘提权。首次快扫所有未知文件仍耗时，名字枚举也有规模成本，不承诺真实大账号秒开。只做必要功能文案，不运行 de-slop/统一前端简化。
